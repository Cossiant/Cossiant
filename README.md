## 个人简介

电源自动化测试工程师，现就职于 Ainuo 智能仪器公司。主要从事电源类产品的自动化测试方案设计、测试上位机开发与产测系统建设。工作内容覆盖仪器通信、SCPI / Modbus 指令解析、测试流程编排、数据采集与结果判定，以及基于 Qt/C++ 的上位机软件工程化。

持续关注嵌入式系统、桌面应用工程化与 AI 辅助开发，习惯将研发和产线测试中的重复流程沉淀为稳定、可维护的工具，并通过 GitHub 开源非涉密项目。

### Ainuo_Communication_Reliability_Test_Software

[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Cossiant/Ainuo_Communication_Reliability_Test_Software)

![Qt](https://img.shields.io/badge/Qt-5.15-41CD52?style=flat-square&logo=qt&logoColor=white)
![SCPI](https://img.shields.io/badge/SCPI-4B8BBE?style=flat-square)
![GPIB / NI-VISA](https://img.shields.io/badge/GPIB_%2F_NI--VISA-2F6690?style=flat-square)
![MIT](https://img.shields.io/badge/License-MIT-2E8B57?style=flat-square)

- 仓库：<https://github.com/Cossiant/Ainuo_Communication_Reliability_Test_Software>
- 概述：基于 Qt/C++ 的仪器通讯可靠性自动化测试软件，当前版本 v3.4.16，MIT License。
- 主要功能：
  - 支持 RS-232 / RS-485、TCP Client、GPIB（NI-VISA），预留 CAN 扩展；
  - 支持 Excel 批量导入 SCPI 指令，自动发送、响应校验与数值 / 字符串范围比对；
  - 支持 AN3.0 HEX 帧解析、异常统计、错误命令导出与多线程任务队列；
  - 使用 QXlsx 进行 Excel 数据处理，ElaWidgetTools 实现 Fluent 风格界面。

- 仓库：<https://github.com/Cossiant/STM32F103ZET6_FreeRTOS_Project>

  - 提供 Keil MDK 与 CMake / GCC ARM 两种构建方式。
